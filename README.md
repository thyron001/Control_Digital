# Prácticas de Control Digital

Este repositorio contiene evidencias de prácticas desarrolladas en el curso de Control Digital, utilizando tableros didácticos integrados por controladores Controllino Mega e interfaces gráficas HMI STONE así como el motor Dc de una planta EPC de DataLights.

## Contenido del repositorio

- **Práctica 1**: Manejo de salidas digitales con Controllino Mega
- **Práctica 2**: Control de LEDs y semáforos usando FSM, entradas digitales y retardos no bloqueantes
- **Práctica 3**: Diseño de interfaz gráfica HMI para control de salidas PWM
- **Práctica 4**: Diseño de controlador PID digital de motor dc con interfaz HMI
- **Control de motor DC**: Diseño e implementación de un controlador integral y de seguimiento de trayectorias de orden cero con observador para un motor DC  

Cada carpeta incluye el código fuente desarrollado, diagramas de estado (cuando aplica), y documentación correspondiente.
